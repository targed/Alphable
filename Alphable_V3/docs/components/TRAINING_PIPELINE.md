# Alphable V3: Training Pipeline Reference

This document covers all data preparation, supervised training, self-play generation, and reinforcement learning modules located in [`src/alphable/training/`](file:///home/targed/Documents/Git/Alphable/Alphable_V3/src/alphable/training).

---

## 1. `prepare_dataset.py` ([`src/alphable/training/prepare_dataset.py`](file:///home/targed/Documents/Git/Alphable/Alphable_V3/src/alphable/training/prepare_dataset.py))

Generates compact, supervised training samples from human and bot Scrabble game replay logs (e.g. Woogles GCG or JSON logs).

### Ingestion & Processing Workflow
1. **Player Identification & Mapping:** Resolves string usernames (e.g., `'BestBot'`, `'CarlSagan121520'`) and aliases to canonical player indices `0` and `1`.
2. **Exact Tile Accounting:**
   - Starts with a standard bag of 86 tiles ($100 - 14$ starting rack tiles).
   - On each play, computes exact tiles placed: $\text{tiles\_used} = \text{len}(\text{rack}) - \text{len}(\text{pos\_rack})$.
   - Accurately decrements bag size: $\text{bag} = \max(0, \text{bag} - \text{tiles\_used})$.
3. **Positive Sample Creation:**
   - Evaluates the played expert move via GADDAG and simulator.
   - Saves positive after-state with target label $+1.0$.
4. **Hard-Negative Pruning & Continuous Deficit Scaling:**
   - Simulates legal alternative plays generated by GADDAG.
   - Maintains a min-heap to keep only the top-$K$ scoring alternative moves (default $K=4$).
   - For alternative moves scoring less than the played move, assigns a continuous target scaled by point deficit:
     $$\text{deficit\_ratio} = \min\left(1.0, \frac{\text{pos\_score} - \text{neg\_score}}{\max(10, \text{pos\_score})}\right)$$
     $$\text{target}_{\text{neg}} = \max(-1.0, 1.0 - 2.0 \times \text{deficit\_ratio})$$
   - Prevents competitive high-scoring alternative plays from being falsely labeled as $-1.0$.

### Multi-Processing Support
- Uses Python `multiprocessing.Pool` with per-worker GADDAG initialization (`init_worker`).
- Processes hundreds of full games in parallel across CPU cores.

## 2. `train_supervised.py` ([`src/alphable/training/train_supervised.py`](file:///home/targed/Documents/Git/Alphable/Alphable_V3/src/alphable/training/train_supervised.py))

Trains `AlphableValueNet` on the supervised dataset of expert after-states.

### Key Features
- **Data Loading:** Uses PyTorch `DataLoader` with 90/10 train/validation split.
- **Optimization:**
  - Optimizer: `optim.AdamW(lr=3e-4, weight_decay=1e-4)`.
  - Loss Function: `nn.MSELoss()`.
  - Scheduler: `ReduceLROnPlateau(factor=0.5, patience=2)`.
- **Early Stopping:** Tracks best validation loss and triggers early stopping after $N$ non-improving epochs (default 4).
- **History Tracking:** Automatically exports epoch metrics (train loss, val loss, time, learning rate) to `<save_path>_history.json` for plotting.

## 3. `self_play.py` ([`src/alphable/training/self_play.py`](file:///home/targed/Documents/Git/Alphable/Alphable_V3/src/alphable/training/self_play.py))

Simulates self-play games to produce reinforcement learning trajectory datasets.

### Capabilities & Modes

#### A. Mirror Self-Play
- Both players (P0 and P1) use the current champion model.
- Includes temperature annealing: samples moves with higher temperature $\tau=0.20$ in early turns to promote exploration, annealing to $\tau=0.10$ in late game.

#### B. Anti-Greedy Curriculum (`--vs-greedy`)
- P0 plays using the neural network while P1 plays as `GreedyBot` (always picking the highest immediate points).
- **Contamination Shield (`--keep-p0-only`):** When training against GreedyBot, passing `--keep-p0-only` ensures only P0's decisions are recorded in the dataset. This prevents GreedyBot's point-chasing plays from being learned by the network when Greedy wins.

#### C. Batched Game Execution
- Groups move evaluations across concurrent games into batched neural network forward passes, maximizing GPU utilization.

#### D. Reward Formulation (`compute_player_target`)
- **Outcome Mode:** Win = $+1.0$, Loss = $-1.0$, Tie = $0.0$.
- **Margin Mode:** Normalized margin $\tanh(\Delta \text{Score} / 150.0)$.
- **Blend Mode (Default):** Combines win/loss anchor with margin bonus:
  $$\text{Target} = (1 - \alpha) \times \text{Outcome} + \alpha \times \tanh\left(\frac{\Delta \text{Score}}{150.0}\right)$$
  With $\alpha = 0.35$.

## 4. `train_rl.py` ([`src/alphable/training/train_rl.py`](file:///home/targed/Documents/Git/Alphable/Alphable_V3/src/alphable/training/train_rl.py))

Trains the value network on self-play outcomes.

### Pipeline
- Warm-starts from previous champion checkpoint (e.g. `models/alphable_v3_supervised_clean.pth` or earlier RL generations).
- Trains with AdamW, learning rate scheduling on plateau, and early stopping.
- Saves best validation checkpoint and exports JSON history logs.
