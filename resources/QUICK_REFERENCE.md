# Alphable Replay Visualizer - Quick Reference

## 🚀 Quick Start

### First Time Setup
```bash
# 1. Install backend dependencies
cd visualizer/backend
pip install -r requirements.txt
cd ../..

# 2. Install frontend dependencies
cd visualizer/frontend
npm install
cd ../..
```

### Run the Visualizer
```bash
# Option 1: Automated (recommended)
./start_visualizer.sh

# Option 2: Manual
# Terminal 1: Backend
cd visualizer/backend && python app.py

# Terminal 2: Frontend  
cd visualizer/frontend && npm start
```

### Access
- Frontend: http://localhost:3000
- Backend API: http://localhost:5000

## 🎮 Generate Games to Watch

```bash
# Create game replays
python evaluate_vs_greedy.py    # → data/vs_greedy/*.json
python evaluate_vs_random.py    # → data/vs_random/*.json
python watch_bot.py             # → data/results/*.json
```

## 🎯 Key Controls

### In the Visualizer
- **Timeline Slider**: Drag to any turn
- **⏮**: Jump to start
- **⏪**: Previous move
- **▶️/⏸**: Play/Pause auto-advance
- **⏩**: Next move
- **⏭**: Jump to end
- **Speed Dropdown**: Change playback speed (0.5x - 5x)
- **Move Log**: Click any move to jump to it

## 🔧 Troubleshooting

### Backend won't start
```bash
cd visualizer/backend
pip install Flask flask-cors
python app.py
```

### Frontend won't start
```bash
cd visualizer/frontend
npm install
npm start
```

**Note**: If you get TypeScript version conflicts during `npm install`, the package.json has been configured to use TypeScript 4.9.5 which is compatible with react-scripts 5.0.1.

### No games showing up
1. Check that JSON files exist in `data/vs_greedy/`, `data/vs_random/`, or `data/results/`
2. Run evaluation scripts to generate games
3. Check backend console for errors
4. Verify backend is running on port 5000

### CORS errors
- Make sure backend is running
- Backend URL in frontend should be `http://localhost:5000`
